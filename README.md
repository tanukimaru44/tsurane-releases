# TSURANE の配布物

Windows 版 TSURANE(つらね)のインストーラを置く場所です。ソースコードはここには置いていません。

## 入れ方

1. 右の **Releases** から最新の `TSURANE-Setup-<版>.exe` を落として実行します(管理者権限は不要です)。
2. すでに入っている場合は、アプリを終了してから実行すると上書き更新になります。会話・関係性・日記などのデータは残ります。
3. 署名を付けていないため、初回は Windows の SmartScreen が警告を出します。「詳細情報」→「実行」で進めてください。

## アプリの中からの更新(0.12.0 以降)

アプリは起動してしばらくすると、ここの Releases に新しい版があるかを確かめます。あれば設定ボタンに印を付けて知らせます。
設定タブの「アプリの更新」で変わったところを読んでから「更新して再起動する」を押した時だけ、新しい版を取ってきて入れ替わります。押すまで勝手には入れ替わりません。

Releases に付いている `latest.yml` と `.blockmap` は、この仕組みが使うファイルです(手で使うものではありません)。
